# Ethics and scope

- All accounts, phone numbers, billers and messages are synthetic. "TakaPay"
  and every biller name are fictional.
- Scam messages are written in the style of common public scam patterns to
  test defences. They are not collected from real victims and contain no
  personal data.
- This project never tests real mobile financial services, apps or accounts.
- If work on this project ever reveals a weakness in a real product, it will
  be reported privately to the provider before any public mention.
- The test set is released to help build defences. Cases are kept to
  realistic, already public scam patterns and do not introduce new real
  world fraud techniques.
